  - System Architecture
  - Frontend Layer → Backend Services → AI/ML Engine
  - Frontend: React.js SPA with responsive UI, role-based dashboards for recruiters, freelancers & admins.
  - Backend: ASP.NET Core Web API (.NET 8/9), clean architecture, JWT authentication, SignalR for real-time chat & notifications.

  - Data Layer: Microsoft SQL Server (150+ performance indexes) + SQLite (AI Service) + MinIO Object Storage (S3-compatible).

--- Slide 13 ---
Layout: Blank
Shapes & Text:
  - AI Workflow – LLM + RAG
  - MAESTA Inc.
  - Page 13
  - AI Workflow
  - LLM Processing → RAG Knowledge Retrieval → Intelligent Response Generation
  - MAESTA leverages a multi-stage AI pipeline to deliver intelligent recruitment and freelancing assistance. User queries are first processed by a Large Language Model (LLM) for intent understanding and context extraction. The RAG (Retrieval-Augmented Generation) layer then fetches relevant knowledge from structured job, candidate, and project databases. Finally, the system synthesizes a precise, context-aware response — powering smart matching, automated screening, and dynamic recommendations in real time.
